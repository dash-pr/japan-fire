# Japan FatFIRE & Real Estate Optimizer

Local dev setup (macOS / Linux):

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

Open http://localhost:5173

This repo contains a single-file React component at `src/FatFIREOptimizer.jsx` implementing the simulation and interactive controls (Vite + Tailwind + Recharts).
